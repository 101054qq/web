# 3D 杯中水互動網頁規格書 v2

## 1. 目標與交付

製作電腦優先的互動網頁，讓使用者自由旋轉透明玻璃杯、注水及倒水，觀察杯內晃動、水流斷裂與飛濺。

**最終交付單一 `index.html`，必須能實際開啟並操作。**

- HTML、CSS、JavaScript、WGSL shader 全部內嵌。
- 使用原生 JavaScript 與 WebGPU，不需要安裝套件或執行建置。
- 不依賴 CDN、外部圖片、字型、模型、網路請求或後端。
- 杯子與場景由程式產生，操作說明直接放在網頁中。
- 最終檔案存放於工作區的 `outputs/index.html`。

## 2. 畫面與操作

採用簡潔玻璃杯風格：透明直筒杯、淡藍色水、淺色背景與柔和光線。杯子中心及鏡頭固定，畫面保留觀看倒水與飛濺的空間。

| 操作 | 行為 |
|---|---|
| 滑鼠左鍵拖曳杯子 | 自由旋轉，可向任意方向傾倒、完全倒置 |
| 放開滑鼠 | 保留杯子姿態，水繼續運動 |
| 按住「注水」或空白鍵 | 固定在杯子上方的水源向下出水 |
| 放開注水操作 | 停止產生新水，已有水流繼續落下 |
| 「扶正」或 `U` | 約 0.5 秒平滑恢復直立，保留水量與運動 |
| 「重置」或 `R` | 回到直立、半杯水，清除外部水流 |

初始為直立、半杯水。注水速度固定，空杯直立時約 6 秒裝滿；滿杯後繼續注水會溢出。水源不跟隨杯口，傾斜時可能部分接住或完全漏接。

第一版不加入杯子平移、鏡頭操作、第二容器、音效、計分或桌面積水。

## 3. 流體與呈現

- 採用 GPU 粒子流體模擬，以 Position Based Fluids 為基礎，包含密度約束、黏性、表面張力及移動杯體碰撞。
- 重力固定向下；杯壁與杯底阻擋水，杯口保持開放。
- 水因杯子旋轉而晃動、撞擊、溢出及飛濺；停止操作後逐漸穩定。
- 杯內、杯外水使用同一套模擬，倒水由物理狀態產生。
- 粒子經表面重建呈現為連續透明水體，帶有反光與厚度效果；小水滴可獨立顯示。
- 流出畫面下方的水移出模擬並回收資源；未注水時水量不自行增加。
- 採用固定時間步與子步進，限制單步杯體旋轉量，避免快速拖曳造成穿透。

## 4. 開啟方式與效能

- 支援具有可用 WebGPU 的桌面 Chrome／Edge。
- 優先驗證直接開啟本機 `index.html`，並另測試以 `localhost` 提供同一檔案。
- 本機檔案的 WebGPU 可用性取決於瀏覽器安全策略；若直接開啟受限，頁面需顯示原因及 localhost 開啟方法。不能只用提示畫面宣稱模擬已可操作。[安全來源規範](https://www.w3.org/TR/secure-contexts/)、[Chrome WebGPU 開啟指引](https://developer.chrome.com/docs/web-platform/webgpu/troubleshooting-tips)
- 啟動時檢查 GPU 能力；初始化失敗或 GPU 中斷時提供中文提示與重新載入入口。
- 以 60 FPS 為目標，效能吃緊時降低渲染解析度、反光與表面細節，保留流體模擬及杯內水量。
- 視窗失焦時停止注水；背景分頁暫停模擬，返回後不補算離開期間。

## 5. 驗收

**實際操作**

- 開啟最終單一檔案，驗證旋轉、注水、倒水、扶正及重置。
- 測試直立、側倒、完全倒置、快速拖曳、空杯注水、满杯溢出與傾斜漏接。
- 杯子停止後水逐漸穩定；無明顯穿壁、憑空增水或大量消失。
- 玻璃與水清楚可辨，水呈現連續表面，無明顯透明遮擋錯誤。
- 按住注水後移出按鈕、放開或失焦，都能確實停止。
- 重置可重複使用，不累積模擬實例或資源。

**獨立性與效能**

- 檔案移到另一個資料夾後仍能使用；斷網時不缺少素材或程式。
- 在開發用 Windows 電腦、1080p 視窗下測試 Chrome／Edge，記錄 GPU、瀏覽器版本及開啟方式。
- 晃動、持續注水各測試 60 秒：目標中位數至少 55 FPS，95% 畫面耗時不超過 33 毫秒。
- 連續操作 10 分鐘無崩潰、數值發散或持續增加的資源占用。
- 交付時附上聊天中的實測結果與檔案連結；未通過項目明確列出。

預設不提供簡化流體替代版本、不要求手機支援，也不公開部署。先完成可操作的流體原型，再加入玻璃與透明水面，最後整合並驗證單一檔案。
